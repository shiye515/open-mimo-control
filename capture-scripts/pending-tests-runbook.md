# 剩余待测抓包步骤（EV / ISO 枚举 / 0x0101）

> 目标：补齐 cmd-map-android-csdk.md「剩余待测」三项
> 流程与上轮完全相同（SysDump TCP DUMP + Copy to sdcard）

## 准备

1. 手机 USB 连电脑、相机开机
2. mimo app 连接相机，**进入预览页**（保持在预览）
3. 拨号 `*#9900#` → **TCP DUMP START** → 把弹窗 key 数字发给电脑侧算 OTP → 输入验证

## 测试序列（每步之间停 10 秒）

| 顺序 | 操作 | 记录 |
|---|---|---|
| 1 | 静置 10 秒（基线） | |
| 2 | **EV**：看清当前 EV 值 → 连调 2 档 → 停 | **改前值、改后值** + 时刻 T1 |
| 3 | 停 10 秒 | |
| 4 | **ISO**：看清当前 ISO → 连调 2 档 → 停 | **改前值、改后值** + 时刻 T2 |
| 5 | 停 10 秒 | |
| 6 | 进一次相册页再返回预览（触发 0x0101） | 时刻 T3 |
| 7 | 停 10 秒 | |

示例记录（发我这种格式即可）：
```
EV 0.0 → +0.6   T1 11:20:15
ISO 100 → 800   T2 11:20:40
相册 T3 11:21:05
```

## 收尾

8. SysDump → **TCP DUMP 停止** → **Copy to sdcard**
9. 告诉我"抓完了"（附上面的记录）

## 电脑侧解析目标（我来做）

- T1 帧 → EV 的 cmd 与编码（验证是否与快门共用 0x2802，值域差异）
- T2 帧 → 0x2a02 单字节与 ISO 实际值的配对 → 反推枚举表
- T3 帧 → 0x0101 的 28 帧结构
