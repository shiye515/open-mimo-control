# 命令参考（commands）

> 全部命令为 DUML 帧（[duml-frame.md](duml-frame.md)），走 UDP 9004 主通道。
> 记法 `(cmdSet, cmdId)`，请求 cmdType=0x40、应答 0xC0、推送 0x00。
> **每条命令均已验证**：真机写入或抓包命令→状态推送对证。样例帧为真实会话抓取。

## 总表

| 功能 | (cmdSet, cmdId) | payload 摘要 | ACK |
|---|---|---|---|
| 模式切换 | 02 / E1 | `[mode]` | cam_status ≤0.4s 变化 |
| 拍照 | 02 / 01 | `01` | 单字节 `00` |
| 录像开始/停止 | 02 / 02 | `01` / `00` | 单字节 `00` |
| 快门速度 | 02 / 28 | `01 [u16] [小数] 00 00 00 40` | 单字节 `00` |
| EV 补偿 | 02 / 2E | `[码]` 单字节 | 单字节 `00` |
| ISO | 02 / 2A | `[枚举]` 单字节 | 单字节 `00` |
| 白平衡 | 02 / 2C | `06 [u16 K/100] 00 00 00` | 单字节 `00` |
| 色彩 | 02 / 42 | `[码]` | — |
| FOV | 02 / 8E | pid 0x0009 TLV | 单字节 `00` |
| 变焦 | 02 / B8 | `01 <0x48+k> <frac> 00` | — |
| 拍照倒计时 | 02 / 4A | `00 01 [秒 u16] [毫秒 u16]` | 单字节 `00` |
| 分辨率/帧率 | 02 / 18 | 见 §分辨率 | — |
| Pro/EIS/ISO MAX/弱光/朝向 | 02 / 8E | TLV（pid 表见 §02/8E） | 单字节 `00` |
| 主题订阅 | 00 / 99 | key 名 TLV（见 [telemetry.md](telemetry.md)） | 回显 req_id |
| RTC 对时 | 00 / 4A | `[年 u16][月][日][时][分][秒][毫秒 u16]` | — |

## 1. 模式切换（02 / E1）

payload `[mode]` 单字节：

| mode | 模式 |
|---|---|
| 0x00 | 慢动作 |
| 0x01 | 视频 |
| 0x02 | 延时摄影 |
| 0x05 | 照片 |
| 0x0A | 运动延时 |
| 0x1A | 直播（未实现建议） |

命令后 `cam_status` 推送的当前模式字节在 ≤0.4s 内变为对应值
（0x01/0x02/0x05/0x0A 均有命令→推送对证）。实时预览流随模式重协商。

## 2. 拍照（02 / 01）与录像（02 / 02）

| 命令 | payload | 语义 |
|---|---|---|
| 02 / 01 | `01` | 拍照（延时摄影模式下为停止延时） |
| 02 / 02 | `01` | 录像开始（视频类模式） |
| 02 / 02 | `00` | 录像停止 |

- ACK：单字节 `00`（成功）；录制期间 `cam_record_time` 推送逐秒递增
- ⚠️ 早期文档曾误读为 `00`=开始——`01`=开始/`00`=停止已双平台真机验证
- 拍照触发时序（Android 实测）：先 02/E1 切照片模式 → 02/01 拍照

## 3. 快门速度（02 / 28）

payload 7 字节：`01 [u16 LE] [小数] 00 00 00 40`

- u16 = `0x8000 | 分母`：`0x8064`=1/100s、`0x8078`=1/120s、`0x80C8`=1/320s
- **小数字节双粒度**（分母含小数时）：
  - ≤9 → 十分位：`0x800C+05` = 1/12.5s、`0x0001+03` = 1.3s
  - ≥10 → 百分位：`0x8001+0x43`(0.67) = 1/1.67s、`0x8001+0x19`(0.25) = 1/1.25s
- 完整样例（1/1.67s）：`01 0180 43 0000 40`；1/1.25s：`01 0180 19 0000 40`
- 秒级长曝直接编码秒值（1.3s = 0x0001+03 十分位形态）
- **视频模式快门上限 1/25s**（更长曝光不可选；拍照模式全表可选）
- 尾字节 0x40 与 0x00 相机均接受
- 写入后 `cam_expo_param` 推送 @20-22（0x8000|分母 + 小数）同步跟随

## 4. EV 补偿（02 / 2E）

payload 单字节 `[码]`：**码 16 = 0EV，1/3 EV 步进**（码域 0x07–0x19）：

```
码：0x07 0x08 0x09 0x0A 0x0B 0x0C 0x0D 0x0E 0x0F 0x10 0x11 0x12 … 0x19
EV：-3.0 -2.7 -2.4 -2.1 -1.8 -1.5 -1.2 -0.9 -0.6  0.0 +0.3 +0.6 … +0.9
```

- 写 -2.0 → 码 0x0A；写 +0.3 → 码 0x11（实测）
- 读：无独立查询——值在 `cam_expo_param` 推送 @6（各模式独立记忆，
  视频模式直读即用户 EV；解析门控与字段地图见 [telemetry.md](telemetry.md)）

## 5. ISO（02 / 2A）

payload 单字节 `[枚举]` = **log2(ISO/50) + 1**：

| payload | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| ISO | 50 | 100 | 200 | 400 | 800 | 1600 | 3200 | 6400 | 12800 |

- 实测：12800→payload 09、6400→08（两帧）
- **仅手动曝光模式可调**（自动模式下该参数由 AE 接管）
- 生效 ISO（AE 实时值）读 `cam_expo_param` @16-17；ISO 档位码 @11

## 6. 白平衡（02 / 2C）

payload 5 字节：`06 [u16 LE: 色温 K/100] 00 00 00`

- 实测：`06 34 00 00 00` = 5200K
- 手动色温模式生效；生效值无推送主题（自动模式下由 AE 管理）

## 7. FOV（02 / 8E，pid 0x0009）

02/8E TLV 写格式：`01 01 <pid u16 LE> 01 <value>`（写）/ `00 01 <pid u16 LE>`（读）。

FOV 码表（OA4）：

| 码 | 名称 | 可用模式 |
|---|---|---|
| 00 | 超广 | 视频模式（与分辨率相关） |
| 01 | 广角 | 全模式 |
| 02 | 标准（畸变校正） | 全模式 |
| 03 | 窄 | 视频模式 |

GET 回读应答：`00 00 01 <pid> 01 <value>`。`cam_fov` 推送存在但值域
（读出区宽高）与设置档位不同源，**FOV 设置以 02/8E 轮询/回读为准**。

## 8. 变焦（02 / B8）

payload `01 <0x48+k> <frac> 00`，zoom = 1 + k + frac（k ∈ 0..2，frac ∈ {0,1}）：

```
01 48 00 00 = 1.0x · 01 48 01 00 = 1.5x · 01 49 00 00 = 2.0x
01 49 01 00 = 2.5x · 01 4a 00 00 = 3.0x · 01 4a 01 00 = 4.0x
```

- 拍照与视频模式均支持 1.0x–4.0x；倍率跨越 3x 边界时相机自动切视角
- `cam_fov` 推送（等效焦距 u32 LE ÷100，24.13mm 基准）随变焦实时跟随，
  UI 倍率 = 焦距 ÷ 24.13

## 9. 拍照倒计时（02 / 4A）

payload 6 字节 `00 01 [秒 u16 LE] [毫秒 u16 LE]`（0/0 = 关闭）：

| 档位 | payload |
|---|---|
| 关闭 | `00 01 0000 0000` |
| 0.5s | `00 01 0000 f401` |
| 1s / 2s / 3s / 5s / 10s | `00 01 0X00 0000`（X=01/02/03/05/0A） |

仅照片模式；7 档全部实测（关闭→0.5→1→2→3→5→10→关闭）。无 GET 形态。

## 10. 参数开关（02 / 8E TLV）

写格式 `01 01 <pid u16 LE> 01 <value>`、读格式 `00 01 <pid u16 LE>`、
应答 `00 00 01 <pid> 01 <value>`、负响应单字节（DF/E3/E0，无 pid）。

| pid | 语义 | 值 |
|---|---|---|
| 0x0000 | Pro 模式开关 | 01 开 / 00 关 |
| 0x0008 | 电子增稳 EIS | 码表 `eisModes` |
| 0x000F | ISO 上限（仅自动曝光） | 码表 isoMaxSteps（04=200/07=1600/09=6400/0A=12800） |
| 0x0014 | 相机物理朝向 | 0 上 / 1 左 / 2 下 / 3 右（3 字节值 `[0,码,0]`） |
| 0x0030 | 弱光增稳开关（仅视频） | 01/00 |
| 0x000A / 0x0018 / 0x0020 / 0x0029 | 语义未定 | ⚠️ 勿盲发 |

负响应归因：单字节结果码不带 pid，依赖本地记录的最近 GET pid
（实现时维护"最近请求"队列）。

## 11. 色彩（02 / 42）与分辨率/帧率（02 / 18）

- 色彩：payload `[码]`——00 普通 / 34 D-Log M（OA4 仅此两档）
- 分辨率/帧率：02/18 写（码表见下）；**读取已迁移 cam_video_param_v2 推送**
  （@0 分辨率码、@1 帧率码，02/19 轮询退役）

| 分辨率码 | 名称 | | 帧率码 | fps |
|---|---|---|---|---|
| 0x10 | 4K 16:9 | | 1 / 2 / 3 | 24 / 25 / 30 |
| 0x2D | 2.7K 16:9 | | 5 / 6 | 50 / 60 |
| 0x0A | 1080p 16:9 | | 7 / 8 | 120 / 240 |
| 0x67 | 4K 4:3 | | 0x0A / 0x13 | 100 / 200 |
| 0x5F | 2.7K 4:3 | | | |

组合约束：4K/2.7K 16:9 至 120fps，1080p 16:9 至 240fps（另 100/200），4K 4:3 至 60fps。

## 12. 通用注意事项

- 参数写入的**生效回读**优先走推送主题（见 [telemetry.md](telemetry.md)），
  仅无推送主题的参数（朝向/ISO MAX/Pro/EIS 等）需要 GET 轮询
- 单字节 `00` ACK 只代表命令受理；**实际生效以对应推送主题为准**
- 未知 pid（0x000A/0x0018/0x0020/0x0029/0x0028/0x0015/0x001F）官方 app 有轮询
  但语义未定——**勿盲发**
