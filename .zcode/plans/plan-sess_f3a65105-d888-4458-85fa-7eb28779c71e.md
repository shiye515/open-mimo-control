# cam_expo_param 全字段破解计划

## Context

`cam_expo_param`（00/99 主题推送，41B）目前只解析了约 11 个字节：EV（锚定 @6）、测光（@15）、"生效 ISO"（@16 u32）、"生效快门"（@20 u16），其中 ISO/快门映射来自 Nano 文档移植、未经 OA4 独立验证——EV 旋拧日志显示 @16-19 出现 1550/1050 等非 ISO 值，疑为测光亮度类参数。目标：建立完整的 41 字节字段地图（每个域的含义/编码/证据），全部实锤后重写解析器。

## Phase 0 — 离线挖掘（无需相机，先做）

1. **写解码工具** `docs/protocol/tools/expo_scan.py`：复用 /tmp/pro-scan/scan.py 的 CRC/帧遍历逻辑（作为仓库工具固化），从 6 个 pcap 提取每条 cam_expo_param 推送（时间戳 + 41B hex）。
2. **字节变化矩阵**：对偏移 0..40 逐一列出 distinct 值 + 变化时刻；与 unknown-signals-report.md 各抓包的已知操作时间线（EV 扫档、ISO MAX、Pro 开关、旋转、变焦、模式切换、倒计时、录制启停）对齐。
3. **交叉验证**：8 份 diag 日志（含 EV 旋拧会话）同法分析。
4. 产出：每字节的假设表（含义候选 / 编码推断 / 置信度 / 证据引用），明确哪些字节恒定、哪些成组变化、哪些是 u16/u32。

## Phase 1 — 受控实验（需相机，用户操作；2-3 次连接会话内完成）

先在 OSMOStatus 恢复实验日志（值变化才记录的 [diag] hex，实验完移除）。

| # | 操作 | 判别目标 |
|---|---|---|
| E1 | 视频自动曝光，EV 从 -3 到 +3 逐档 | EV 域 + 伴随参数 |
| E2 | ISO MAX 200↔12800 逐档 | **判别 @16-19 是 ISO 还是亮度**（ISO MAX 变 → 生效 ISO 应变） |
| E3 | 手动曝光：快门逐档 → ISO 逐档 → 回自动 | 快门/ISO 在手动下的编码 |
| E4 | 白平衡 自动→手动→色温逐档 | 流内是否有 kelvin u16 |
| E5 | 六模式循环切换 ×2（视频/照片/慢动作/延时/运动延时/夜景） | **窗口漂移定律**：每模式的固定布局 or 真滑动窗口 |
| E6 | 变焦 1→2→4→1 | 流内是否含 lens 位置 |
| E7 | 录制 5s 启停 | 录制态域 |
| E8 | 色彩 普通↔D-Log M | 色彩域 |
| E9 | 不动任何设置，遮挡镜头→对准亮灯 | 测光域确认 + @16-19 亮度/ISO 歧义判别 |
| E10 | Pro 开关、弱光增稳开关 | 是否有映照 |

## Phase 2 — 定律提炼

- 产出字段地图：偏移 / 大小 / 类型 / 编码 / 含义 / 证据（实验编号）
- 窗口模型定论：若每模式布局固定，EV 锚定机制可简化为「模式→偏移」表
- 置信分级：实锤（≥2 个独立操作对应 + 编码合理 + 其余时间稳定）／推定／未知

## Phase 3 — 落地

- `OSMOStatus.parseExpoParam` 全字段解析：实锤域进快照专属字段（新增有意义者，如白平衡/亮度），未知域保留原始 hex
- golden 单测：从真实抓包帧做 fixture，逐域锁死
- 文档：新建 `docs/protocol/cam-expo-param.md`（完整字段地图 + 证据链）；更新 topics-catalog.md 第 8 行、control-channel.md EV 节交叉引用
- 移除实验日志，终版装机
