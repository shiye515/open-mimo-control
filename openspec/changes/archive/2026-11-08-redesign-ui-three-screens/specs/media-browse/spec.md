# Spec Delta

## Purpose

提供素材浏览页的页面外壳与导航：从控制页进入，展示相机 SD 卡剩余容量与三列缩略图网格布局（视频/照片角标样式）。素材文件列表、下载、删除等协议能力本期未接入，页面以空态呈现。

## ADDED Requirements

### Requirement: 素材浏览页导航
应用必须（SHALL）提供素材浏览页：从控制页底部左侧素材浏览图标按钮进入；页面左上角提供返回图标按钮，点击返回控制页；在素材浏览页停留期间控制会话必须（SHALL）保持不断开。

#### Scenario: 从控制页进入
- **WHEN** 用户在控制页点击底部左侧素材浏览图标
- **THEN** 应用进入素材浏览页，页面显示标题与 SD 剩余容量

#### Scenario: 返回控制页
- **WHEN** 用户点击左上角返回图标按钮
- **THEN** 应用返回控制页，控制页预览与遥测保持离开前状态，会话不断开

### Requirement: 素材浏览页布局
素材浏览页必须（SHALL）按设计稿 `docs/design/ui-design-preview.html`（⑦）提供布局：顶部标题行（返回图标按钮、标题「素材浏览」、SD 剩余容量）；主体为三列缩略图网格区域，网格项采用设计稿的缩略图样式（视频项带播放角标、文件名与时长标注，照片项区分样式），网格区域可滚动；整体深色风格与设计稿一致。

#### Scenario: 布局与设计稿对照
- **WHEN** 用户进入素材浏览页
- **THEN** 返回按钮、标题、SD 剩余容量与三列网格区域可见，风格与设计稿素材浏览页一致

### Requirement: 素材数据边界（本期未接入）
素材文件列表、下载、删除协议本期不实现：无素材数据时页面必须（SHALL）展示明确的空态提示，不得（SHALL NOT）展示伪造的缩略图数据，也不得（SHALL NOT）提供不可用的下载/删除操作入口。

#### Scenario: 空态展示
- **WHEN** 素材浏览页无素材数据（协议未接入或相机无文件）
- **THEN** 网格区域展示空态提示（如「素材协议尚未接入」），不显示任何缩略图数据
