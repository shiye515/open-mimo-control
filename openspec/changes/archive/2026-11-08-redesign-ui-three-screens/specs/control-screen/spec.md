# Spec Delta

## MODIFIED Requirements

### Requirement: 拍摄参数设置
应用必须（SHALL）提供拍摄参数设置面板，覆盖当前拍摄模式支持的设置项，每项"设置 → 相机应答 → 回读校准"：

| 设置项 | 命令 | 约束 |
|---|---|---|
| 曝光模式 | `02/1E`（01 自动/04 手动；读 `02/1F`） | 优先级模式（02/03）不支持 |
| ISO | `02/2A`（码 03-0C = 100-51200；读 `02/2B`） | 仅手动曝光（自动下 E3） |
| 快门 | `02/28`（u16+十分位速度编码；读 `02/29`） | 仅手动曝光（自动下 DF）；50 档速度表 1/8000s-30s |
| EV 补偿 | `02/2E`（10+三分位，±3EV；读 cam_expo_param） | 仅自动曝光 |
| 白平衡 | `02/2C`（00 自动/06 手动 2000-10000K 步进 100；读 `02/2D`） | |
| 色彩档位 | `02/42`（Normal/Normal 10-bit/D-Log M；读 cam_image_effect） | |
| 锐度 / 降噪 | `02/38` / `02/44`（s8；读 cam_image_effect） | |
| 视角 FOV | `02/8E` 参数 0x0009 | 视频模式仅 窄(02)/标准·畸变校正(01)；其他模式仅 标准·畸变校正(01)/广角(05) |
| 防抖 EIS | `02/8E` 参数 0x0008（关/RockSteady/HorizonSteady/RockSteady+/HorizonBalancing） | |

设置值域必须（SHALL）按 OA4 参数表驱动；参数值必须（SHALL）以查询/主题推送回读为准展示（生效值来自 cam_expo_param：自动曝光下的实际 ISO 与快门、EV 补偿与测光）；设置变更可能重启编码器（预览暂停数秒），必须（SHALL）不误判为流故障；格式类设置成功后必须（SHALL）重发 live view 请求以恢复推流。

#### Scenario: 手动曝光下设置 ISO 与快门
- **WHEN** 曝光模式为手动时用户选择 ISO 3200 与快门 1/50s
- **THEN** 相机应用参数，回读后面板显示生效值

#### Scenario: 自动模式下手动设置被拒
- **WHEN** 曝光模式为自动时用户尝试设置 ISO
- **THEN** 相机应答 E3，界面提示"自动曝光下不可手动设置"，不改变面板状态

#### Scenario: 模式切换后设置刷新
- **WHEN** 拍摄模式切换后设置面板重新打开
- **THEN** 各设置项显示该模式当前生效值（模式独立记忆）

#### Scenario: 相机端改动同步
- **WHEN** 用户在相机机身改变某设置
- **THEN** 面板在下一次回读（周期或订阅推送）后反映新值

#### Scenario: 视角菜单按模式约束
- **WHEN** 用户打开视角菜单
- **THEN** 视频模式下仅可选 窄、标准（畸变校正）；其他模式仅可选 标准（畸变校正）、广角

### Requirement: 主界面布局
应用必须（SHALL）提供单屏主控制界面，布局与设计稿 `docs/design/ui-design-preview.html`（④—⑧）一致，整体深色风格：
- 顶部状态两行：第一行展示电量百分比与电池温度、SD 卡容量；第二行展示分辨率/帧率、FOV、曝光概要；顶部不展示录制时长与录制模式，录制时长仅出现在预览左上角 REC 角标。
- 实时预览区为固定高度圆角预览卡片，位于状态区下方，卡片左上角仅显示 REC 录制角标（录制中按秒计时并闪烁红点）。
- 拍摄参数面板无折叠标题，直接平铺当前拍摄模式的全部参数项（曝光/图像/格式等分组），占满预览区与底部操作栏之间的区域；内容超出面板时在面板内部滚动，顶部状态区与底部操作栏位置保持固定。
- 底部操作栏固定于页面底部：左侧素材浏览图标按钮（进入素材浏览页）、中央快门按钮（待机录制模式为红色圆环、录制中为红色方块、照片模式为白色实心圆）、右侧录制模式图标按钮（图标跟随当前拍摄模式）。
- 相机状态详情（全量遥测、诊断复制、断开连接）收进顶部状态区的详情入口，不再常驻控制页；回放、更多菜单、用户入口不再提供。

#### Scenario: 布局与参考截图对照
- **WHEN** 应用连接相机后进入主界面
- **THEN** 上述元素全部可见，布局与 docs/design/ui-design-preview.html 控制页状态一致；录制时长仅出现在预览左上角 REC 角标，顶部无录制模式与录制时长

#### Scenario: 参数面板滚动
- **WHEN** 参数项总高度超过预览区与底部操作栏之间的可用空间
- **THEN** 参数面板内部滚动，顶部状态区与底部操作栏位置保持不变

#### Scenario: 未连接状态
- **WHEN** 尚未与相机建立会话
- **THEN** 主界面不展示遥测数据与实时画面，并引导用户进入连接流程

### Requirement: 模式切换
应用必须（SHALL）允许用户通过录制模式弹窗切换已实现的拍摄模式（运动延时、延时摄影、慢动作、视频、照片）：点击底部操作栏右侧录制模式图标按钮，从底部弹出六项模式弹窗（含直播展示项），当前模式高亮，选择后弹窗收起；命令为 `02/E1`（照片 05/视频 01/超级夜景 28/慢动作 00/延时 02/运动延时 0A），切换结果必须（SHALL）反映相机实际工作模式（`02/80` 字节 57），底部录制模式按钮图标必须（SHALL）跟随当前拍摄模式更新；每个拍摄模式独立记忆曝光/格式参数，模式切换成功后必须（SHALL）延迟重新查询并刷新参数面板；模式切换必须（SHALL）在录制进行中被禁止或先安全停止录制；直播模式不在实现范围，选择直播必须（SHALL）不向相机发送任何命令并给出明确的未实现提示。

#### Scenario: 打开与关闭模式弹窗
- **WHEN** 用户点击底部右侧录制模式图标按钮
- **THEN** 从底部弹出六项模式弹窗，当前模式高亮；点击取消或弹窗外部区域关闭弹窗

#### Scenario: 切换到照片模式
- **WHEN** 用户在待机状态下于弹窗中选择"照片"模式
- **THEN** 相机切换为照片模式，右下角录制模式图标切换为照片图标，快门按钮语义变为拍照（白色实心圆），参数面板刷新为照片模式的参数

#### Scenario: 录制中切换模式
- **WHEN** 用户在录制进行中选择其他模式
- **THEN** 应用先停止录制（或拒绝切换并提示），不得造成相机状态不一致

#### Scenario: 选择直播模式
- **WHEN** 用户在弹窗中选择"直播"
- **THEN** 应用不发送命令，展示明确的"未实现"提示，当前拍摄模式保持不变

## REMOVED Requirements

### Requirement: 视场角展示与变焦限制
OA4 为 Action 系列，无变焦与云台命令（三开源仓库一致：`02/B8` 变焦与 `04/xx` 云台仅适用于 Pocket 系列；官方 Mimo 对 OA4 的数字变焦命令未定案）。应用必须（SHALL）展示当前视场角设置（FOV，`02/8E` 参数 0x0009）；预览区捏合手势必须（SHALL）不向相机发送任何变焦命令，并给出明确的"变焦未实现"提示。

#### Scenario: 捏合手势不发命令
- **WHEN** 用户在预览区执行捏合手势
- **THEN** 应用不发送变焦命令，展示"变焦未实现（OA4 无变焦命令）"提示

#### Scenario: FOV 展示
- **WHEN** 相机 FOV 设置变化（应用内或相机端）
- **THEN** 预览区/设置面板展示当前 FOV（超广/广/标准/自然广）

**Reason**: 2026-11-08 官方 Mimo 抓包（captures/zoom-capture-20261108-113607.pcap）实锤 OA4 已实装数码变焦：02/B8 方向+时间命令（01 <rate> <1进/0出> 00、0A 4E <lens> 绝对位置、ff000000 停止），"无变焦命令"的前提废止。
**Migration**: 由下方 ADDED「视场角展示与数码变焦」承接；视角展示保留（值域见「拍摄参数设置」视角行）。

### Requirement: 菜单与设置入口
**Reason**: 设计稿新控制页不包含"…更多菜单 / 主页返回 / 回放 / 用户入口"，该要求与旧参考截图（docs/reference/IMG_1926.PNG）绑定，随本次布局重构废止。
**Migration**: 功能入口由「主界面布局」（素材浏览图标、详情入口）与「模式切换」（模式弹窗）承担；回放等能力待素材协议接入后另行立项。

## ADDED Requirements

### Requirement: 导航与会话操作入口
控制页必须（SHALL）提供：底部左侧素材浏览图标按钮，点击进入素材浏览页；顶部状态区可展开相机状态详情面板，包含全量遥测、诊断信息复制与「断开连接」操作，作为会话操作与真机排查入口。

#### Scenario: 进入素材浏览页
- **WHEN** 用户点击底部左侧素材浏览图标按钮
- **THEN** 应用进入素材浏览页，返回后控制页连接与状态保持不变

#### Scenario: 展开详情并断开连接
- **WHEN** 用户展开相机状态详情并点击「断开连接」
- **THEN** 会话关闭，应用回到连接页

### Requirement: 视场角展示与数码变焦
应用必须（SHALL）展示当前视角设置（FOV，02/8E 参数 0x0009，按模式约束值域）并提供数码变焦控制：仅拍照与视频模式提供（拍照 1.0x–4.0x、视频 1.0x–2.0x，0.1x 精度）；控制入口为参数面板「变焦」行，点击弹出变焦轮盘（0.1x 步进刻度、整数焦段磁吸与触觉反馈），拖动跨过刻度时实时发送绝对位置命令、松手磁吸并发送最终位置；其他模式不支持变焦，不提供入口。变焦命令 02/B8 为方向+时间语义（2026-11-08 官方 Mimo 抓包实锤，osmo-client 同源互证）：
- 绝对位置：`0A 4E <lens u16 LE> 00`，lens = 126 × 倍率（OA4 实测单位：1.0x=126、2.0x=252、4.0x=504）；
- 方向增量：`01 <rate> <1 进 / 0 出> 00`，rate 为速率档（0x48/0x49/0x4a，官方 App 渐进加速），按住期间以 ~10Hz 重复发送；
- 停止：`ff 00 00 00`（松手必须发送，否则相机持续变焦）。
倍率回读：cam_lens_state 主题 offset 14 的 u16 lens ÷ 126。变焦跨越 3x 边界时相机可能自动切换视角（官方行为），必须（SHALL）以回读校准视角显示。

#### Scenario: 轮盘变焦
- **WHEN** 用户点击「变焦」行并在弹出的变焦轮盘上拖动（0.1x 刻度，整数焦段磁吸）后松手
- **THEN** 应用发送 02/B8 绝对位置命令（lens = 126 × 倍率），预览画面呈现相机端变焦效果，倍率角标与轮盘值更新；轮盘量程按模式约束（视频 1.0x–2.0x / 拍照 1.0x–4.0x）

#### Scenario: 不支持变焦的模式
- **WHEN** 用户切换到延时摄影/慢动作/运动延时/超级夜景模式
- **THEN** 参数面板不显示「变焦」入口，预览不提供变焦操作

#### Scenario: 捏合手势方向变焦
- **WHEN** 用户在预览区按住捏合手势
- **THEN** 应用按 ~10Hz 发送方向增量命令（捏开=进、捏拢=出），松手发送停止命令；焦距由方向与持续时间决定

#### Scenario: 变焦倍率回读
- **WHEN** 相机端或应用内变焦后
- **THEN** 面板倍率显示以 cam_lens_state 回读校准（lens ÷ 126）

#### Scenario: FOV 展示
- **WHEN** 相机视角设置变化（应用内或相机端）
- **THEN** 预览区/设置面板展示当前视角（窄/标准（畸变校正）/广角）
