# Spec Delta: live-view

## Purpose

接收相机的实时视频流并低延迟渲染为全屏预览，包含预览辅助元素（构图网格线），并在流异常时自愈，为远程控制提供"所见即所得"的画面基础。

## ADDED Requirements

### Requirement: 实时画面渲染
控制会话建立后，应用必须（SHALL）接收相机视频流并将其解码渲染为全屏预览；从会话建立到首帧画面展示必须（SHALL）在数秒内完成，端到端延迟必须（SHALL）低到可支撑取景与构图操作。

#### Scenario: 首帧展示
- **WHEN** 控制会话握手成功且相机开始推流
- **THEN** 应用在数秒内展示实时画面，画面方向与相机朝向一致

#### Scenario: 支持相机当前分辨率
- **WHEN** 相机以某分辨率/帧率档位推流
- **THEN** 应用正确解码该档位画面，无明显花屏或持续丢帧

### Requirement: 预览辅助元素
应用必须（SHALL）在预览画面上提供可开关的三分构图网格线，默认状态必须（SHALL）与参考运行截图一致（开启）。

#### Scenario: 网格线开关
- **WHEN** 用户切换网格线开关
- **THEN** 预览画面上网格线随之显示或隐藏，且设置在本次会话内保持

### Requirement: 流异常自愈
应用必须（SHALL）在出现丢包、乱序或个别帧损坏时自愈画面，无需重建控制会话；当视频流持续中断时，应用必须（SHALL）给出可感知的提示并尝试仅重建视频流。

#### Scenario: 短时丢包恢复
- **WHEN** 网络抖动导致少量丢包
- **THEN** 画面在短时间内恢复正常播放，控制会话保持不变

#### Scenario: 视频流中断
- **WHEN** 视频流停止但控制会话仍存活
- **THEN** 界面给出流中断提示，并自动尝试恢复视频流；恢复成功后画面继续展示
