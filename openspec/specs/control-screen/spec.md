# control-screen Specification

## Purpose

提供与官方 Mimo 远程控制界面（参考截图 docs/reference/IMG_1926.PNG）对应的独立 iOS 控制主界面：状态条、模式选择、录制/拍照、拍摄参数设置、菜单入口，是用户操作相机的主要交互面。

> 控制命令基线（2026-11-07 修订）：协议路线为 osmocam datalink（[osmocam](https://github.com/luisreysan/osmocam)、[osmo-client](https://github.com/luisreysan/osmo-client)、[osmosis](https://github.com/KonradIT/osmosis) 三开源仓库互证，OA4 实测），控制命令全集以 osmo-client `camlink/camera.py`（命令集 0x02 → receiver 0x01）为准。OA4 不发布 `camcap_*` 能力主题（全部应答 01），各模式值域硬编码为 OA4 参数表。

## Requirements

### Requirement: 主界面布局
应用必须（SHALL）提供单屏主控制界面，布局与设计稿 `docs/design/ui-design-preview.html`（④—⑧）一致，整体深色风格：
- 顶部状态两行：第一行展示电量百分比与电池温度、SD 卡容量；第二行展示分辨率/帧率、FOV、曝光概要；顶部不展示录制时长与录制模式，录制时长仅出现在预览左上角 REC 角标。
- 实时预览区为固定高度圆角预览卡片，位于状态区下方，卡片左上角仅显示 REC 录制角标（录制中按秒计时并闪烁红点）。
- 拍摄参数面板无折叠标题，按两组直接平铺当前拍摄模式的全部参数项：第一组「通用设置」按优先级排列分辨率、帧率、视角、变焦、电子增稳（仅视频模式）、弱光增稳（仅视频模式）、网格，并包含画幅、拍照倒计时（仅照片模式）、延时间隔/拍摄时长/保存（仅延时模式）、延时速率（仅运动延时模式）等条件项（慢动作模式以组合格式项替代分辨率/帧率；照片模式无分辨率/帧率与变焦）；第二组「图像」按 PRO 开关、曝光、EV、Shutter、ISO、ISO MAX、白平衡、色彩、锐度、降噪排列；Pro 关闭时仅显示 PRO（曝光与专业参数全部隐藏，02/8E pid 0x0000：SET 01=开/00=关）。面板占满预览区与底部操作栏之间的区域；内容超出面板时在面板内部滚动，顶部状态区与底部操作栏位置保持固定。
- 底部操作栏固定于页面底部：左侧素材浏览图标按钮（进入素材浏览页）、中央快门按钮（待机录制模式为红色圆环、录制中为红色方块、照片模式为白色实心圆）、右侧录制模式图标按钮（图标跟随当前拍摄模式）。
- 相机状态详情（全量遥测、诊断复制、断开连接）收进顶部状态区的详情入口，不再常驻控制页；回放、更多菜单、用户入口不再提供。

#### Scenario: 布局与参考截图对照
- **WHEN** 应用连接相机后进入主界面
- **THEN** 上述元素全部可见，布局与 docs/design/ui-design-preview.html 控制页状态一致；录制时长仅出现在预览左上角 REC 角标，顶部无录制模式与录制时长

#### Scenario: 参数面板滚动
- **WHEN** 参数项总高度超过预览区与底部操作栏之间的可用空间
- **THEN** 参数面板内部滚动，顶部状态区与底部操作栏位置保持不变

#### Scenario: 未连接状态
- **WHEN** 尚未与相机建立会话
- **THEN** 主界面不展示遥测数据与实时画面，并引导用户进入连接流程

### Requirement: 录制控制
应用必须（SHALL）通过录制按钮控制相机录制，命令按拍摄模式分派：视频/超级夜景/慢动作/运动延时用录制命令 `02/02`（载荷 01 开始 / 00 停止）；延时摄影为间隔拍摄，启停必须（SHALL）走拍照命令 `02/01`（`02/02` 在延时模式下被相机以 DF 拒绝）。录制状态必须在按钮形态与顶部时长计时上同步反映，且必须（SHALL）与相机真实录制状态（`02/80` 推送字节 0 的 bits 6-7：空闲/启动中/录制中/停止中）一致。

#### Scenario: 开始与停止录制（视频类模式）
- **WHEN** 用户在视频模式下点击录制按钮，随后再次点击
- **THEN** 相机开始录制（按钮变为停止形态、顶部时长开始计时），再次点击后停止，时长保留最终值

#### Scenario: 延时模式启停分派拍照命令
- **WHEN** 用户在延时摄影模式下点击录制按钮
- **THEN** 应用发送 `02/01`（而非 `02/02`）启停间隔拍摄，按钮与时长状态同样同步

#### Scenario: 命令失败反馈
- **WHEN** 录制命令未被相机确认（如存储卡不可写，结果码 D8）
- **THEN** 按钮不进入录制态，界面给出失败原因提示

### Requirement: 模式切换
应用必须（SHALL）允许用户通过录制模式弹窗切换已实现的拍摄模式（运动延时、延时摄影、慢动作、视频、照片）：点击底部操作栏右侧录制模式图标按钮，从底部弹出六项模式弹窗（含直播展示项），当前模式高亮，选择后弹窗收起；命令为 `02/E1`（照片 05/视频 01/超级夜景 28/慢动作 00/延时 02/运动延时 0A），切换结果必须（SHALL）反映相机实际工作模式（`02/80` 字节 57），底部录制模式按钮图标必须（SHALL）跟随当前拍摄模式更新；每个拍摄模式独立记忆曝光/格式参数，模式切换成功后必须（SHALL）延迟重新查询并刷新参数面板；模式切换必须（SHALL）在录制进行中被禁止或先安全停止录制；直播模式不在实现范围，选择直播必须（SHALL）不向相机发送任何命令并给出明确的未实现提示。

#### Scenario: 打开与关闭模式弹窗
- **WHEN** 用户点击底部右侧录制模式图标按钮
- **THEN** 从底部弹出六项模式弹窗，当前模式高亮；点击取消或弹窗外部区域关闭弹窗

#### Scenario: 切换到照片模式
- **WHEN** 用户在待机状态下于弹窗中选择"照片"模式
- **THEN** 相机切换为照片模式，右下角录制模式图标切换为照片图标，快门按钮语义变为拍照（白色实心圆），参数面板刷新为照片模式的参数

#### Scenario: 录制中切换模式
- **WHEN** 用户在录制进行中选择其他模式
- **THEN** 应用先停止录制（或拒绝切换并提示），不得造成相机状态不一致

#### Scenario: 选择直播模式
- **WHEN** 用户在弹窗中选择"直播"
- **THEN** 应用不发送命令，展示明确的"未实现"提示，当前拍摄模式保持不变

### Requirement: 拍照控制
在照片模式下，应用必须（SHALL）通过快门按钮触发相机拍照（`02/01 [01]`），并以拍照成功反馈（如画面闪烁/缩略提示）确认。

#### Scenario: 拍照成功
- **WHEN** 用户在照片模式下点击快门且相机执行成功
- **THEN** 应用收到相机确认并给出拍摄成功反馈

### Requirement: 拍摄参数设置
应用必须（SHALL）提供拍摄参数设置面板，覆盖当前拍摄模式支持的设置项，每项"设置 → 相机应答 → 回读校准"：

| 设置项 | 命令 | 约束 |
|---|---|---|
| PRO 开关 | `02/8E` pid 0x0000（01 开/00 关，开 2026-11-09 抓包实锤、关 2026-11-10 真机实测） | 连接即回读；Pro 关闭时曝光与全部专业参数隐藏 |
| 曝光模式 | `02/1E`（01 自动/04 手动；读 `02/1F`） | 仅 Pro 开启时显示；优先级模式（02/03）不支持 |
| ISO | `02/2A`（码 03-0A = 100-12800，OA4 上限 12800；读 `02/2B`） | 仅 Pro 开启时显示；自动曝光下置灰（仅手动可调） |
| 快门 | `02/28`（u16+小数字节编码，双粒度：≤9 十分位 / ≥10 百分位；读 `02/29`） | 仅 Pro 开启时显示；自动曝光下置灰（仅手动可调）；56 档速度表 1/8000s-30s（含 1/1.67=0x438001、1/1.25=0x198001，2026-11-10 抓包实锤）；视频模式下限 1/25s（真机实测，更长曝光不可选） |
| EV 补偿 | `02/2E`（单字节码 07h-19h：码16=0EV，每码 1/3EV 共 19 档，显示一位小数（-2.7/+0.3），零为 "+0"，默认 -3（码07）；读 cam_expo_param） | 仅 Pro 开启时显示（自动/手动均可调）；交互为底部滚轮弹窗（系统 wheel，逐档震动/音效，滚动 200ms 节流下发、关闭补发尾档） |
| ISO MAX | `02/8E` pid 0x000F（码 01=100 … 08=12800，App 值域 200-12800 七档；读同 pid） | 仅 Pro 开启时显示，自动/手动均可调 |
| 白平衡 | `02/2C`（00 自动/06 手动 2000-10000K 步进 100；读 `02/2D`） | |
| 色彩档位 | `02/42`（普通 00 / D-Log M 0x34，OA4 实测仅两档；读 cam_image_effect） | |
| 图像调节 | 无独立相机字段（三方文档 02/8E pid 表仅 aspect/FOV/EIS）；App 侧预设经 `02/38`+`02/44` 下发：默认=锐度0/降噪0、人像=锐度0/降噪1，本地记忆档位 | 默认/人像/自定义三档；仅自定义开放锐度/降噪设置 |
| 锐度 / 降噪 | `02/38` / `02/44`（s8；读 cam_image_effect） | 仅图像调节为自定义时可调，否则置灰 |
| 视角 FOV | `02/8E` 参数 0x0009 | 视频模式：窄(03)/标准·畸变校正(02)/广角(01)/超广(00)，是否可选随分辨率与帧率变化（相机裁决，拒绝时回读校准）；其他模式：标准·畸变校正(02)/广角(01) |
| 电子增稳 EIS | `02/8E` 参数 0x0008（关闭/超强增稳[RockSteady]/地平线增稳[HorizonSteady]/超强增稳+[RockSteady+]/地平矫正[HorizonBalancing]） | 仅视频模式显示 |
| 弱光增稳 | `02/8E` pid 0x0030（01 开/00 关；2026-11-10 Mimo 抓包实锤：4 次开关 SET 交替，GET 回读真机验证） | 仅视频模式显示；连接即回读校准 |
| 取景网格 | 无命令（App 端预览叠加：关闭/网格线/网格线和对角线，本地记忆） | 官方 Mimo 同款为 App 端叠加，不影响相机 |
| 拍照倒计时 | `02/4A`（载荷 [00 01, 秒 u16 LE, 毫秒 u16 LE]，0/0=关闭；2026-11-10 Mimo 抓包实锤 8 帧，无 GET 回读形态） | 仅照片模式显示；值域 关闭/0.5/1/2/3/5/10s（camcap_countdown 能力表），App 本地记忆当前值 |

设置值域必须（SHALL）按 OA4 参数表驱动；参数值必须（SHALL）以查询/主题推送回读为准展示（生效值来自 cam_expo_param：自动曝光下的实际 ISO 与快门、EV 补偿与测光）；设置变更可能重启编码器（预览暂停数秒），必须（SHALL）不误判为流故障；格式类设置成功后必须（SHALL）重发 live view 请求以恢复推流。

#### Scenario: 手动曝光下设置 ISO 与快门
- **WHEN** 曝光模式为手动时用户选择 ISO 3200 与快门 1/50s
- **THEN** 相机应用参数，回读后面板显示生效值

#### Scenario: 自动模式下手动设置被拒
- **WHEN** 曝光模式为自动时用户尝试设置 ISO
- **THEN** 相机应答 E3，界面提示"自动曝光下不可手动设置"，不改变面板状态

#### Scenario: 模式切换后设置刷新
- **WHEN** 拍摄模式切换后设置面板重新打开
- **THEN** 各设置项显示该模式当前生效值（模式独立记忆）

#### Scenario: 相机端改动同步
- **WHEN** 用户在相机机身改变某设置
- **THEN** 面板在下一次回读（周期或订阅推送）后反映新值

#### Scenario: 视角菜单按模式约束
- **WHEN** 用户打开视角菜单
- **THEN** 视频模式下仅可选 窄、标准（畸变校正）；其他模式仅可选 标准（畸变校正）、广角

### Requirement: 视频/照片格式切换
应用必须（SHALL）支持视频格式切换（`02/18 [分辨率, 帧率, 00, 00, 慢动作倍速]`，读 `02/19`）与照片格式切换（`02/12 [尺寸, 比例]`，读 `02/13`，仅照片模式），值域按 OA4 参数表驱动：

- 视频：4K(0x10)/2.7K(0x2D)/1080p(0x0A)/4K 4:3(0x67)/2.7K 4:3(0x5F)；帧率 4K·2.7K 16:9 最高 120、1080p 最高 240、4K 4:3 最高 60
- 超级夜景：4K/2.7K/1080p，24-30fps；延时：4K/2.7K/1080p，25/30fps；运动延时：仅 30fps
- 慢动作：(4K/2.7K/1080p, 120fps, 4×) 与 (1080p, 240fps, 8×)，倍速入 `02/18` 末字节
- 照片：单一尺寸（约 10MP，拒绝 L/M），比例 4:3(`00 00`)/16:9(`00 01`)

OA4 拒绝 aspect 单独设置（`02/8E` 0x0046 应答 E3），格式命令必须（SHALL）单独发送不携带 aspect 写；格式切换后必须（SHALL）回读校准。

#### Scenario: 切换视频分辨率与帧率
- **WHEN** 视频模式下用户选择 1080p/240fps
- **THEN** 相机应用格式并重启编码器（预览暂停数秒后恢复），回读显示 1080p/240

#### Scenario: 慢动作格式带倍速
- **WHEN** 慢动作模式下选择 4K/120fps
- **THEN** `02/18` 携带倍速 4×，回读确认

#### Scenario: 画幅切换
- **WHEN** 照片模式下切换比例 4:3 ↔ 16:9
- **THEN** 相机应用并回读确认（尺寸固定不变）

### Requirement: 延时/运动延时参数设置
应用必须（SHALL）支持延时参数设置（`02/6C` timelapse 形：保存类型 00 仅视频/02 JPEG/03 RAW + 间隔 u16 单位 0.1s + 时长 u32 秒 0=不限）与运动延时速度设置（`02/6C` hyperlapse 形：速度 u16，0=自动），当前值必须（SHALL）从 cam_lapse_param 主题回读展示。

#### Scenario: 设置延时间隔与时长
- **WHEN** 延时模式下用户设置间隔 2.0s、时长不限
- **THEN** 相机应用参数，cam_lapse_param 推送后面板显示间隔 2.0s

#### Scenario: 设置运动延时速度
- **WHEN** 运动延时模式下选择速度 15×
- **THEN** 相机应用参数并回读确认

### Requirement: 控制命令应答与错误统一
全部控制命令必须（SHALL）单发等待应答（同一时刻至多一条在途命令），应答首字节结果码统一映射为 CommandError：00 成功；E0 命令不支持；E3 参数非法或当前状态不允许；DF 当前不可用；D8 存储不可用。失败必须（SHALL）反馈原因且不改变 UI 状态；任何设置项的实际值必须（SHALL）以回读结果为准。

#### Scenario: 结果码反馈
- **WHEN** 命令应答结果码为 E0/E3/DF/D8
- **THEN** 界面给出对应语义的失败提示（如 DF="当前不可用"）

#### Scenario: 失败不改 UI 状态
- **WHEN** 设置命令失败
- **THEN** 面板不进入新值状态，回读刷新为相机实际值

### Requirement: 断连状态呈现
会话断开期间，应用必须（SHALL）禁用录制/拍照/模式切换/设置变更等相机操作，并持续展示断开与重连状态。

#### Scenario: 断连期间操作被禁用
- **WHEN** 会话断开且重连尚未成功时用户点击录制
- **THEN** 应用不发送命令，界面提示当前已断开

### Requirement: 导航与会话操作入口
控制页必须（SHALL）提供：底部左侧素材浏览图标按钮，点击进入素材浏览页；顶部状态区可展开相机状态详情面板，包含全量遥测、诊断信息复制与「断开连接」操作，作为会话操作与真机排查入口。

#### Scenario: 进入素材浏览页
- **WHEN** 用户点击底部左侧素材浏览图标按钮
- **THEN** 应用进入素材浏览页，返回后控制页连接与状态保持不变

#### Scenario: 展开详情并断开连接
- **WHEN** 用户展开相机状态详情并点击「断开连接」
- **THEN** 会话关闭，应用回到连接页

### Requirement: 视场角展示与数码变焦
应用必须（SHALL）展示当前视角设置（FOV，02/8E 参数 0x0009，按模式约束值域）并提供数码变焦控制：仅拍照与视频模式提供（拍照 1.0x–4.0x、视频 1.0x–2.0x，0.1x 精度）；控制入口为参数面板通用设置组的「变焦」行，点击弹出变焦轮盘（0.1x 步进刻度、整数焦段磁吸与触觉反馈），拖动跨过刻度时实时发送绝对位置命令、松手磁吸并发送最终位置；其他模式不支持变焦，不提供入口。变焦命令 02/B8 为方向+时间语义（2026-11-08 官方 Mimo 抓包实锤，osmo-client 同源互证）：
- 绝对位置：`0A 4E <lens u16 LE> 00`，lens = 126 × 倍率（OA4 实测单位：1.0x=126、2.0x=252、4.0x=504）；
- 方向增量：`01 <rate> <1 进 / 0 出> 00`，rate 为速率档（0x48/0x49/0x4a，官方 App 渐进加速），按住期间以 ~10Hz 重复发送；
- 停止：`ff 00 00 00`（松手必须发送，否则相机持续变焦）。
倍率回读：cam_lens_state 主题 offset 14 的 u16 lens ÷ 126。变焦跨越 3x 边界时相机可能自动切换视角（官方行为），必须（SHALL）以回读校准视角显示。

#### Scenario: 轮盘变焦
- **WHEN** 用户点击「变焦」行并在弹出的变焦轮盘上拖动（0.1x 刻度，整数焦段磁吸）后松手
- **THEN** 应用发送 02/B8 绝对位置命令（lens = 126 × 倍率），预览画面呈现相机端变焦效果，倍率角标与轮盘值更新；轮盘量程按模式约束（视频 1.0x–2.0x / 拍照 1.0x–4.0x）

#### Scenario: 不支持变焦的模式
- **WHEN** 用户切换到延时摄影/慢动作/运动延时/超级夜景模式
- **THEN** 参数面板不显示「变焦」入口，预览不提供变焦操作

#### Scenario: 捏合手势方向变焦
- **WHEN** 用户在预览区按住捏合手势
- **THEN** 应用按 ~10Hz 发送方向增量命令（捏开=进、捏拢=出），松手发送停止命令；焦距由方向与持续时间决定

#### Scenario: 变焦倍率回读
- **WHEN** 相机端或应用内变焦后
- **THEN** 面板倍率显示以 cam_lens_state 回读校准（lens ÷ 126）

#### Scenario: FOV 展示
- **WHEN** 相机视角设置变化（应用内或相机端）
- **THEN** 预览区/设置面板展示当前视角（窄/标准（畸变校正）/广角）
