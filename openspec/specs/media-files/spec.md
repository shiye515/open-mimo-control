# media-files Specification

## Purpose

通过相机 datalink 与 HTTP 通道查询、浏览、下载、删除相机存储的媒体文件，为素材浏览页提供真实数据：媒体（回放）模式的进入与维持、分页文件清单、缩略图获取、文件下载与删除。

## Requirements

### Requirement: 媒体模式进入与维持
应用必须（SHALL）进入媒体（回放）模式并在素材浏览页存续期间维持：优先尝试 `02/0C [01 01 00 01]`；若应答错误码或约 1 秒内 `02/80` 的 mediaMode 位（byte3 bit6）未置位（OA4 / Pocket 系实测一律以 E0 拒绝 `02/0C`），改发 `01/01` 控制脉冲——先 `03 00000000 04000000 07 01` 约 6 帧（~20Hz），再 `00 00000000 04000000 04 01` 以 ~20Hz 持续直至 mediaMode 置位（唯一完成信号，OA4 约 350ms 内置位）。维持期必须（SHALL）以约 1Hz 发送 `00/88` 子命令 `0x17` 心跳（14B，字节 5-7 为 ASCII "APP"），否则相机约 1 秒后自动脱离媒体模式。无专用退出命令：离开素材浏览页时停止维持，相机自行返回拍摄模式，应用必须（SHALL）随后恢复实时预览。进入后必须（SHALL）等待至少 1.7 秒再发起首个列表查询。

#### Scenario: 进入媒体模式（OA4 路线）
- **WHEN** 用户进入素材浏览页且会话已建立
- **THEN** 应用先尝试 02/0C，mediaMode 未置位时改发 01/01 脉冲直至 mediaMode 置位，随后启动 1Hz 维持心跳并等待 1.7 秒

#### Scenario: 离开媒体模式
- **WHEN** 用户从素材浏览页返回控制页
- **THEN** 应用停止维持心跳，相机自行返回拍摄模式，实时预览恢复

### Requirement: 分页文件清单
应用必须（SHALL）以 `00/26` 分页查询文件清单（页大小 ≤45）：游标 `0x00000001` 取 SD 卡最新一页，游标传上一页最旧的视频文件句柄取更早一页；应答为 `00/27` 分块流（start/data/end 三种子类型，10 字节子头含 counter 回显与页内序号），必须（SHALL）仅按 DUML 命令（00/27）过滤分块，拼接后按「最后数据块（长度 bit12 置位）+ 其前全部序号到齐」判定清单完整；清单为 `[u32 数量][记录…]`，记录以 `19 06` 标记锚定，解析出：文件名与扩展名（TLV `0d`）、媒体路径（TLV `1a` 子类 01，无扩展名）、缩略图路径（TLV `1a` 子类 02）、句柄（T-10）、字节大小（T-14）、时长秒（T-6，视频）、类型（T-2：03 视频 / 00 照片）、分辨率与帧率码（T-3/T-4）、FAT 打包时间（T-18）；清单中出现 `0c 01` TLV 表示已到库末尾。相邻页以媒体路径去重（相机按一页一条重叠返回）。

#### Scenario: 拉取最新一页
- **WHEN** 进入媒体模式后发起游标 `0x00000001` 的查询
- **THEN** 应用收到 00/27 分块并解析出不超过 45 条文件记录（含文件名、大小、句柄、类型、缩略图路径）

#### Scenario: 加载更早文件
- **WHEN** 用户请求加载更早文件且上一页存在视频句柄
- **THEN** 应用以该句柄为新游标再次查询，新页文件与已有列表按媒体路径去重后合并

#### Scenario: 未挂载即查询
- **WHEN** 进入媒体模式不足 1.7 秒即查询或存储正忙
- **THEN** 相机以空流应答（仅 start 无 data/end），应用对该存储重试查询而不判定为无文件

### Requirement: 缩略图获取
应用必须（SHALL）通过相机 HTTP 服务（80 端口）`GET /v2?storage=<0|1>&path=<缩略图路径>.THM` 获取 JPEG 缩略图并缓存；存储索引以文件句柄 bit30（置位=内置存储=1，否则 SD=0）判定，OA4 仅 SD 卡（storage=0）。

#### Scenario: 网格展示缩略图
- **WHEN** 文件列表就绪
- **THEN** 网格项展示对应 .THM 缩略图（视频/照片角标区分），缩略图请求失败时展示占位图且不影响列表

### Requirement: 文件下载
应用必须（SHALL）支持通过 `GET /v2?storage=<0|1>&path=<媒体路径>.<扩展名>` 下载原文件到应用沙盒，展示下载进度，支持 Range 断点续传（206），下载完成提供系统分享/存储反馈。

#### Scenario: 下载视频原文件
- **WHEN** 用户在文件详情中选择下载
- **THEN** 文件写入沙盒并展示进度，完成后可再次下载时提示已存在

### Requirement: 文件删除
应用必须（SHALL）以 `00/28 [count][handles u32-LE…][counter u32-LE] 00 [count u32-LE] 01 01 00 00` 删除文件，应答 `0000` 为成功；删除必须（SHALL）经用户确认后执行，同一句柄不得重复发送删除命令；删除成功后本地列表移除该文件。

#### Scenario: 确认后删除
- **WHEN** 用户在文件详情中选择删除并确认
- **THEN** 应用发送删除命令，收到 `0000` 后从列表移除该文件；应答非 `0000` 时提示失败原因且文件保留
